# PRA32-U2 Editor for Renoise

## Release Notes (v1.0.0)

### 🎉 新規リリース

Renoise用エクステンションとして **PRA32-U2 Editor** を初公開しました。  
PRA32-U2ハードウェアシンセサイザーをRenoise上から直感的にコントロール可能です。

***

## ✨ 主な特徴

### ✅ PRA32-U2専用エディタ

* PRA32-U2の全主要パラメータに対応
* MIDI CCによるリアルタイム編集
* Renoise内からの即時サウンドデザイン

### ✅ MIDIコントロール完全対応

以下のような幅広いパラメータをサポート：

* OSC制御（Wave / Shape / Morph / Pitchなど）
* ミキサー（OSC Mix / Noise / Sub）
* フィルター（Cutoff / Resonance / EG Amount / Key Tracking）
* エンベロープ（Filter / Amp）
* LFO（Wave / Rate / Depth / Modulation）
* ボイス設定（Mode / Assign / Portamento）
* エフェクト（Chorus / Delay）
* 各種モジュレーション（Aftertouch / Breath / Velocity）

👉 MIDI CCベースで細かく制御可能

***

## 🆕 PRA32-Uからの主な変更点

### 🌊 Osc Drift の追加（重要）

* 新たに **Osc Drift (CC#82)** を搭載
* アナログライクなピッチ揺らぎを再現可能
* サウンドに「有機的な揺れ」と「厚み」を付加

***

## 🔧 その他の拡張点

### 🎛 新規パラメータ

* Osc Saw Wave Mode (CC#83)
* Voice Assign Mode (CC#110)
* Aftertouch LFO Amount (CC#109)

### 🎚 エフェクト強化

* Chorus（Level / Rate / Depth）
* Delay（Mode / Time / Feedback）

### 🧠 表現コントロール向上

* Breath Controller対応
* Velocity Sensitivity強化
* Aftertouchモジュレーション対応

***

## 🎹 MIDI仕様ハイライト

* ポリフォニック対応（Mode 3）
* Note / Aftertouch / Pitch Bend対応
* Control Changeによる詳細制御

***

* Renoiseでハードウェア音源を統合したいユーザー
* PRA32-Uからアップグレードしたユーザー
* モジュレーションを活用した音作りが好きなユーザー
